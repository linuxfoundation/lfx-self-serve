Every mailing list has three settings. You choose them in step 2 of the create form (**Mailing List Settings**), and you can change them later by editing the list. This article is for people who can manage mailing lists for a project or foundation.

| Setting                | Question it answers                       |
| ---------------------- | ----------------------------------------- |
| **Audience & Access**  | Who can discover and join this list?      |
| **Posting Permission** | How do conversations happen on this list? |
| **Visibility**         | Who can read past discussions?            |

## Audience & Access

This controls who can discover and join the list.

- **Public** (recommended): anyone can subscribe. Most projects start here.
- **Approval Required**: people must request access and be approved.
- **Invite Only**: only invited subscribers can join.

Only **Public** lists show a **Join** button to people browsing the **Mailing Lists** page. See [Manage Mailing Lists](../manage-mailing-lists/). For the other two, subscribers are added by someone who manages the list. See [Manage Subscribers](../manage-subscribers/).

## Posting Permission

This controls how conversations happen on the list.

- **Open Discussion** (recommended): anyone can post. Best for open community discussion.
- **Moderated Discussion**: subscribers can post, but messages require moderation.
- **Announcement**: only moderators can post. Best for official updates.

To make someone a moderator, set their role on the list's page. See [Manage Subscribers](../manage-subscribers/).

On the **Mailing Lists** page, the **Posting** column shows each list's setting to people who manage lists.

## Visibility

This defines who can read past discussions.

- **Public**: past discussions can be read by anyone.
- **Subscribers only**: past discussions can be read only by subscribers. The list's page shows this as **Members Only**, and the **Mailing Lists** page shows the list without the **Public** check mark.

Two rules apply to visibility:

- **Subscribers only is permanent.** When you select it, a note appears: "Once selected, 'Subscribers only' visibility cannot be changed to public later. This is a permanent privacy setting from Groups.io." If a list is already **Subscribers only**, the **Public** option is turned off when you edit it. Think about it before you choose it.
- **Announcement lists must be Public.** If you choose **Announcement** posting with **Subscribers only** visibility, you see "Announcement mailing lists must have public visibility." and can't continue until you change one of them.

## Change a setting

1. Open the **Mailing Lists** page for the project or foundation.
2. Select the list's name to open it.
3. Select **Edit Mailing List**.
4. Go to the **Mailing List Settings** step, change the setting, and select **Next** until the last step.
5. Select **Save Changes**. You see "Mailing list updated successfully".

On the list's page, the **Enabled Features** card shows the current **Audience & Access**, **Posting Permission**, and **Visibility** for the list. Hover over an item to see what it controls.
