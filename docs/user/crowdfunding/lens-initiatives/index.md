A crowdfunding initiative can be run on behalf of a project, foundation, or organization. LFX Self Serve lists those initiatives under that entity's lens, so its writers can follow fundraising run in its name. The page works like the **Me** lens [Initiatives](../view-initiatives/) page, scoped to the selected entity.

## Who sees it

- **Project and Foundation lenses** — users who can write to the selected project or foundation.
- **Org lens** — users with a writer role granted directly on the selected organization. A role on a parent organization does not carry over.

Other users don't see the navigation item.

## Navigation

1. Sign in to [app.lfx.dev](https://app.lfx.dev).
2. Switch to the **Project**, **Foundation**, or **Org** lens and select the project, foundation, or organization.
3. Select **Crowdfunding Initiatives** from the left navigation sidebar.

## What the page shows

The page header reads **Initiatives**, with the description "Fundraising initiatives on LFX Crowdfunding run on behalf of" followed by the entity name. Below it, you get the same stats bar (**Active Initiatives**, **Total Raised**, **Total Sponsors**), the **Active**, **Pending**, and **Archived** filter pills, and the **New Initiative** button as the Me lens page. See [View Initiatives](../view-initiatives/) for details.

Select an initiative to open its detail page. It offers the same tabs and actions described in [Manage Initiatives](../manage-initiatives/), except **Edit attribution**, which is available only to the initiative's creator from the **Me** lens.

## Error states

- **You don't have access to these initiatives** — only writers on the project, foundation, or organization can see the initiatives run on its behalf. Ask an administrator of that entity for write access.
- **Initiatives couldn't be loaded** — LFX Crowdfunding is unavailable right now. Select **Try again** after a moment.
