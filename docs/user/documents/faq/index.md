## Who can see project documents?

Document visibility depends on your persona. If you cannot see expected documents, contact your project administrator.

## Why don't I see any documents?

Make sure you have the correct project or foundation selected in the lens switcher. Documents are scoped to a specific context. If the correct context is selected and you still see no documents, your project may not have any documents uploaded yet. Also check that the source tab above the list is set to **All** and that the search box is empty.

## Can I download documents?

Yes. Use the **Download** icon on the row of an uploaded file; hover over a row's icon to see its action. Documents added as links open in a new tab with **Open link**, and meeting recordings open with **Play recording**. There is no separate detail page for a document.

## Can I upload documents?

Yes, if you have write access to the active project or foundation. Use **Upload Files** above the documents list. If you don't see the **Upload Files**, **New Folder**, and **Add Link** buttons, you don't have write access. Contact your project administrator.

## Can I organize documents into folders?

Yes, with write access. Select **New Folder**, name it, then choose that folder when you upload files or add links. Select a folder in the list to open it, and use the breadcrumb to go back.

## Can I add a link instead of a file?

Yes, with write access. Select **Add Link**, enter the **Link URL** and a **Title**, and optionally choose a folder.

## Where do meeting recordings and summaries appear?

Recordings, transcripts, summaries, and meeting attachments appear in the **Meetings** tab, and in **All**. Use **Play recording** to open a recording and **Preview** to read a summary.

## Who do I contact if a document is missing or incorrect?

Contact your project administrator or LFX support. Include the document name and the project it belongs to.

## What happened to My Documents?

The Me-lens **My Documents** page has been removed. Switch to a project or foundation to see its documents.
