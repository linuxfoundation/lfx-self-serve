The Admin area lists every mentorship program you administer, whatever state it is in.

## Before you begin

- Sign in at [app.lfx.dev](https://app.lfx.dev).
- You must be a Program Admin on at least one program. If you administer none, the list is empty and you can enroll one.

## Steps

1. Open [app.lfx.dev/mentorship/admin](https://app.lfx.dev/mentorship/admin).
2. Narrow the list with the **Search** box and the **Filter By Status** filter (**All statuses**, or one status).
3. Select a program card to open its detail page, with its **Current Mentees**, **Past Mentees**, **Mentors** and **Terms** tabs. A program in **Pending Review** shows only **Terms**.
4. To offer a new program, select **Enroll a Program**. See [Enroll a Program](../enroll-a-program/).

The list shows twelve programs at a time. Select **Load more** to see the next twelve.

## Add a missing logo

A program in **Pending Review**, **Open** or **Completed** that has no logo shows a **Logo missing** hint on its card, with an **Add logo** button.

1. Select **Add logo** on the card.
2. Pick a JPG or PNG file, 420 × 420 px, 2 MB or smaller.

You see **Logo added.** and the list reloads.

## Program page actions

The top of a program's detail page has these actions:

| Action               | What it does                                                                                                                                                      |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **View Public Page** | Opens the program's page on [mentorship.linuxfoundation.org](https://mentorship.linuxfoundation.org) in a new tab. It shows on every program, whatever its status |
| **Edit Program**     | Opens the program's form with its saved answers. Changes are saved when you select **Update**, and do not change the program's review status                      |
| **Hide Program**     | In the **⋯** menu on an **Open** or **Completed** program. See [Hide or Show a Program](../program-visibility/)                                                   |
| **Unhide Program**   | In the **⋯** menu on a **Hidden** program. See [Hide or Show a Program](../program-visibility/)                                                                   |

The **⋯** menu sits next to **Edit Program**. A program in **Pending Review** or **Rejected** has no **⋯** menu.

## Program status

| Status             | What it means                                  |
| ------------------ | ---------------------------------------------- |
| **Open**           | Approved and running                           |
| **Pending Review** | Submitted and awaiting Linux Foundation review |
| **Completed**      | Its terms have finished                        |
| **Rejected**       | Not approved during review                     |
| **Hidden**         | Removed from public listings                   |

## Troubleshooting

| What you see                                               | What it means                                                                      |
| ---------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| "No access to this program"                                | You are not a Program Admin on it. Ask an existing admin to add you.               |
| "We could not load this program. Try again."               | A transient failure reading the program.                                           |
| "You don't have permission to change this program's logo." | Your account can't change this program. Ask another Program Admin to add the logo. |
