The Admin area lists every mentorship program you administer, whatever state it is in.

## Before you begin

- Sign in at [app.lfx.dev](https://app.lfx.dev).
- You must be a Program Admin on at least one program. If you administer none, the list is empty and you can enroll one.

## Steps

1. Open [app.lfx.dev/mentorship/admin](https://app.lfx.dev/mentorship/admin).
2. Filter by program status.
3. Select a program card to open its detail page, with its **Current Mentees**, **Past Mentees**, **Mentors** and **Terms** tabs.
4. To offer a new program, select **Enroll a Program**. See [Enroll a Program](../enroll-a-program/).

The list is paged twelve programs at a time.

## Program status

| Status             | What it means                                  |
| ------------------ | ---------------------------------------------- |
| **Open**           | Approved and running                           |
| **Pending Review** | Submitted and awaiting Linux Foundation review |
| **Completed**      | Its terms have finished                        |
| **Rejected**       | Not approved during review                     |
| **Hidden**         | Removed from public listings                   |

## Troubleshooting

| What you see                                 | What it means                                                        |
| -------------------------------------------- | -------------------------------------------------------------------- |
| "No access to this program"                  | You are not a Program Admin on it. Ask an existing admin to add you. |
| "We could not load this program. Try again." | A transient failure reading the program.                             |
