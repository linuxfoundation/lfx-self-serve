A reviewer note records context on an application — screening outcome, strengths, concerns — for the other people reviewing it.

## Who can see a note

The note is saved to the application and is visible to **every admin and mentor of that program**. It is **not** visible to the mentee.

## Before you begin

You must be a Program Admin or an approved mentor on the program.

## Steps

1. Open the program and find the applicant, on **Current Mentees** as an admin or on **Applicants** as a mentor.
2. Select **Add note**.
3. Write the note in the **Reviewer note** dialog. Up to 2,000 characters, with a live counter.
4. Save.

To clear a note, empty it and save.

## After completing

You see **Note saved** (or **Note cleared**). The note is available to the program's other reviewers straight away.

## Troubleshooting

| What you see                                                                    | What it means                                |
| ------------------------------------------------------------------------------- | -------------------------------------------- |
| "You can no longer edit notes on this program. Refresh the page and try again." | You are no longer an admin or mentor on it.  |
| "This application no longer exists. Refresh the page and try again."            | The application was withdrawn or removed.    |
| "Could not save the note"                                                       | A transient failure; the note was not saved. |
