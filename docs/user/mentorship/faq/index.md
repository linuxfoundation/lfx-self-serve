## For mentees

### How many programs can I apply to at once?

You can have up to three applications open at a time. Withdrawing an application frees a slot straight away.

### My application says "Not Selected" — what happened?

The program declined it for that term. You can apply to a different program, or to the same program in a later term.

### Why can't I mark my task as Submitted?

A task cannot be submitted for one of four reasons:

- **The task is still in To Do.** Move it to **In Progress** first.
- **It needs a file you have not uploaded.** The row says "This task needs a file before it can be submitted. Upload one first." Upload it — that submits the task for you, so there is no separate step.
- **The due date has passed.** "The due date has passed, so this task can no longer be submitted."
- **Your mentor already marked it complete.** "Completed tasks can only be changed by your mentor."

### What is the difference between Prerequisite Tasks and Tasks?

Prerequisite tasks are part of your application and come before a decision. Tasks are the term's work and appear once you are accepted.

### Can I undo a withdrawal?

No, a withdrawal cannot be undone. You would have to apply again, and the term may have closed in the meantime.

### Where do I actually apply?

Find the program at [mentorship.linuxfoundation.org](https://mentorship.linuxfoundation.org) and select **Apply to This Program**. That brings you back into LFX Self Serve with the program and term already set.

## For mentors

### How do I join a program?

There are two ways onto a program, and they do not work the same:

- **A Program Admin invites you.** Accepting the invitation puts you straight onto the program; no further approval is needed.
- **You raise a request yourself.** Pick the program under **Select LFX Mentorship** on the registration form at [app.lfx.dev/mentorship/mentor](https://app.lfx.dev/mentorship/mentor), or later from **Mentor Profile → Edit Mentor Profile → Select LFX Mentorship**. That one waits for a Program Admin to approve it.

You cannot request a program from **My Programs** — that tab only lists the programs you already mentor.

### Why doesn't my invitation link work?

Invitation links can only be used once, and only by the account the email was sent to. If the page says the invitation is for a different account, sign in with that one. Otherwise, ask the Program Admin to invite you again.

### Can I decide on an application?

No, mentors cannot accept or decline applications. Mentors review applicants, set and review tasks, and leave reviewer notes. Accepting, declining, withdrawing and graduating are Program Admin actions.

### How do I contact my mentees?

Mentorship does not show mentees' contact details to mentors. Use the channels your program has set up with its mentees. Program Admins can find mentees' email addresses with **Download By Status** (see [Export Mentees](../export-mentees/)).

### Who can see my reviewer note?

Every Program Admin and mentor on that program can see your note. The mentee cannot.

## For Program Admins

### When do I invite mentors?

You invite mentors after the program is approved, from the **Mentors** tab. Search for the person in **Search and select mentors...** by name, LF username or full email address, pick them, and select **Invite**. Enrolling a program does not invite mentors. See [Manage a Program's Mentors](../manage-mentors/).

### How many open terms can a program have?

A program can have up to four open terms at a time.

### What does "Decline by Term" do?

It declines every **pending** application in the term you pick. Accepted mentees are not affected, and it cannot be undone.

### What happens if I graduate a mentee with unfinished tasks?

You can graduate a mentee who still has unfinished tasks. The confirmation tells you how many are not Submitted or Completed before you go ahead.

### Why did my decision fail and the list refresh?

The application had already changed before your decision was saved — either someone else decided first, or its status moved for another reason. Check the new status before acting again.

### Why does my logo upload fail?

A logo is rejected when it is the wrong format, the wrong size, or too large a file. It must be JPG or PNG, 420 × 420 px, and 2 MB or smaller. SVG is not accepted. If the program saved but the logo did not, add it later with **Add logo** on the program card. See [Your Programs (Program Admin)](../admin-programs/).

### How do I see my program's public page?

Open the program from [app.lfx.dev/mentorship/admin](https://app.lfx.dev/mentorship/admin) and select **View Public Page**. It opens the program's page on [mentorship.linuxfoundation.org](https://mentorship.linuxfoundation.org) in a new tab.

### How do I hide a program from the public site?

Open the program and select **Hide Program** from the **⋯** menu. Only an **Open** or **Completed** program can be hidden, and not while it has active applications. Select **Unhide Program** on a **Hidden** program to show it again. See [Hide or Show a Program](../program-visibility/).

## Statuses

### What is the difference between Rejected and Declined?

**Rejected** applies only to a program that was not approved during review. **Declined** applies to an application that was turned down, whether it was a mentee or a mentor application.
