**My Programs** lists every program you mentor or have asked to mentor.

## Before you begin

Sign in at [app.lfx.dev](https://app.lfx.dev) and go to **Mentorship → Mentor → My Programs**. You need a mentor profile.

## Steps

1. Open [app.lfx.dev/mentorship/mentor/programs](https://app.lfx.dev/mentorship/mentor/programs).
2. Filter by program status — **Open** or **Completed**.
3. Select a program to open its detail page.
4. To join a new program, raise a request from this tab. To pull one you have raised, withdraw it.

## Request status

| Status | What it means |
|---|---|
| **Pending** | Raised and awaiting the Program Admin's decision — whether you asked or they invited you |
| **Approved** | You mentor the program |
| **Declined** | The Program Admin did not approve it |
| **Withdrawn** | The request was pulled |

## After completing

An approved program opens on its detail page, with **Tasks**, **Mentees** and **Applicants** tabs.
