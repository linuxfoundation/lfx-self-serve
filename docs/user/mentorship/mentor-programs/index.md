**My Programs** lists every program you mentor. It is a plain list of cards — you request programs and withdraw requests from your mentor profile, not from here.

## Before you begin

Sign in at [app.lfx.dev](https://app.lfx.dev) and go to **Mentorship → Mentor → My Programs**. You need a mentor profile.

## See the programs you mentor

1. Open [app.lfx.dev/mentorship/mentor/programs](https://app.lfx.dev/mentorship/mentor/programs).
2. Select a program card to open its detail page, with **Tasks**, **Mentees** and **Applicants** tabs. **Tasks** is selected first.

Only approved programs appear here. A request still waiting on a Program Admin does not, which is why the tab can look empty just after you ask: "Request to join a program from your mentor profile to get started."

## Request to mentor a program

1. Go to the **Mentor Profile** tab.
2. Select **Edit Mentor Profile**.
3. Under **Mentorship Program Details**, open **Select LFX Mentorship** and pick the program. You can type to search.

**Selecting the program sends the request immediately.** It does not wait for you to save, and closing the panel with **Cancel** does not take it back — **Save** only persists edits to the profile fields. If you picked the wrong program, withdraw the request from its row.

A program you have already requested, already mentor, or were declined for is not offered in the list. Withdrawing a request puts the program back in the list, and you can ask again.

## Withdraw a request

In the same section, the table lists your programs with their status. A request still pending shows a **Withdraw** action on its row — this is the only way to undo a request, including one sent by mistake. Approved and declined rows have none. To leave a program you already mentor, ask one of its Program Admins to remove you.

## Request status

| Status        | What it means                                                                            |
| ------------- | ---------------------------------------------------------------------------------------- |
| **Pending**   | Raised and awaiting the Program Admin's decision — whether you asked or they invited you |
| **Approved**  | You mentor the program; it now appears under My Programs                                 |
| **Declined**  | The Program Admin did not approve it                                                     |
| **Withdrawn** | You pulled the request; you can ask again                                                |

An invitation a Program Admin sent you appears in the same table, with **Accept** and **Decline** actions. Accepting an invitation puts you straight onto the program — unlike a request you raise yourself, which waits for a Program Admin to approve it.

## After completing

An approved program opens on its detail page, with **Tasks**, **Mentees** and **Applicants** tabs. **Tasks** is selected first.
