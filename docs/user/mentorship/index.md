The Mentorship section is where you take part in an LFX Mentorship program. It covers three surfaces, one per role: **Mentee**, **Mentor**, and the **Admin** area for Program Admins.

## What you can do

- Register as a mentee, apply to programs, and complete the tasks a program sets
- Register as a mentor, join programs, and review what your mentees submit
- As a Program Admin, enroll a program, run its terms, decide on applications, and manage its mentors and tasks

## Who this applies to

| Role | Where it lives | Who it is for |
|---|---|---|
| **Mentee** | [app.lfx.dev/mentorship/mentee](https://app.lfx.dev/mentorship/mentee) | Anyone applying to or taking part in a program |
| **Mentor** | [app.lfx.dev/mentorship/mentor](https://app.lfx.dev/mentorship/mentor) | Project contributors who review a mentee's work |
| **Program Admin** | [app.lfx.dev/mentorship/admin](https://app.lfx.dev/mentorship/admin) | People who administer a project's program |

A single person can hold more than one role. Each surface is reached on its own and has its own tabs.

## Navigation

Go to **app.lfx.dev** and select **Mentorship** from the left navigation sidebar. The public catalogue of programs lives separately at [mentorship.linuxfoundation.org](https://mentorship.linuxfoundation.org), which is also where you start an application from.

## Key concepts

- **Program**: a project's mentorship offering. A program has a status that decides whether it is listed and whether it can take applications.
- **Term**: the dated run of a program. A program may have several terms; a term is **Open** or **Closed**.
- **Application**: one person's request to join a program for a term, as a mentee or a mentor. The `role` distinguishes them, and the status vocabulary is shared.
- **Task**: work assigned to a mentee. A **prerequisite** task is part of an application; a non-prerequisite task is the term's work. A task can require a file upload.
- **Reviewer note**: free text saved on an application and visible to every admin and mentor of that program — not to the mentee.
- **Program Admin**: the person who administers a program. Not the same thing as an upstream project maintainer.

## Program status

| Status | Meaning |
|---|---|
| **Open** | Approved and running |
| **Pending Review** | Awaiting LFX review after enrollment |
| **Completed** | The program's terms have finished |
| **Rejected** | Not approved during review |
| **Hidden** | Removed from public listings |

**Rejected** applies only to a program. An application that is turned down is **Declined**.

## Application status

| Status | Mentee sees | Meaning |
|---|---|---|
| **Pending** | In Review | Submitted, awaiting a decision |
| **Accepted** | Accepted | On the term |
| **Declined** | Not Selected | Not taken on for this term |
| **Withdrawn** | Withdrawn | Pulled, by the mentee or on their behalf |
| **Graduated** | Graduated | Finished the term successfully |
| **On Hold** | On Hold | Parked by the program |
