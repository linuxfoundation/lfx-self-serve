When a program is enrolled, reviewers receive an email with approve and reject links. Both open the same review page in LFX Self Serve.

## Before you begin

Use the link in the review email. It opens `/mentorship/program-review/:programId` with the decision pre-selected.

## Steps

1. Select **Approve** or **Reject** in the review email.
2. Sign in at [app.lfx.dev](https://app.lfx.dev) if prompted.
3. Review the program on the page.
4. Select **Confirm**.

The page records the decision only when you confirm, so a mail scanner that prefetches the link cannot approve or reject anything.

## After completing

| Decision    | Program status becomes                                        |
| ----------- | ------------------------------------------------------------- |
| **Approve** | Approved — the program is published and can take applications |
| **Reject**  | Rejected — the program is not listed                          |

**Rejected** is reserved for programs. An application that is turned down is **Declined**.
