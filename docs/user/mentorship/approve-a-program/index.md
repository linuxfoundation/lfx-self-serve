When a program is enrolled, reviewers receive an email about it. Its links open the program's review page in LFX Self Serve, where you can see the program and decide.

## Before you begin

Only members of the mentorship approver team can approve or reject a program. Anyone without access to the program who opens the link sees a message that they don't have permission.

## Steps

1. Open a link in the review email.
2. Sign in at [app.lfx.dev](https://app.lfx.dev) if prompted.
3. Review the program on the page:
   - **Header** — the program logo, name, status and the project it belongs to.
   - **Program description** and **Program skills**.
   - **Links and compliance** — the GitHub repository, the Code of Conduct and the OpenSSF Best Practices (CII) badge. Each shows **Not provided** when the program has none.
4. Decide in the **Review request** card:
   - To approve, select **Approve program**.
   - To reject, select **Reject**, then **Reject program**. Select **Cancel** to go back.

Opening a link never records a decision. The page records one only when you select **Approve program** or **Reject program**, so a mail scanner that prefetches the link cannot approve or reject anything. The email's reject link opens the page with the reject step already open.

## After completing

| Decision    | Program status becomes                                        |
| ----------- | ------------------------------------------------------------- |
| **Approve** | Approved — the program is published and can take applications |
| **Reject**  | Rejected — the program is not listed                          |

A decision cannot be undone from the review page. If another reviewer decided the program first, the page says so and shows the status they recorded. A program that was already decided shows its status, without the decision buttons.

**Rejected** is reserved for programs. An application that is turned down is **Declined**.
