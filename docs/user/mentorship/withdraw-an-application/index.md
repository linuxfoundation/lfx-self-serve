Withdrawing pulls an application you no longer want to pursue and frees one of your three slots.

## Before you begin

- The application must still be pending. An accepted application is not withdrawn this way — talk to the program first.
- Withdrawing cannot be undone. You would have to apply again, and the term may have closed by then.

## Steps

You can withdraw from the **Overview** tab or from **Application History**. Both ask you to confirm in the same dialog.

### From the Overview tab

1. Open [app.lfx.dev/mentorship/mentee/overview](https://app.lfx.dev/mentorship/mentee/overview).
2. Find the application card you want to pull.
3. Select **Withdraw**.
4. In the **Withdraw Application** dialog, select **Withdraw**.

### From Application History

1. Open [app.lfx.dev/mentorship/mentee/profile](https://app.lfx.dev/mentorship/mentee/profile).
2. Scroll to **Application History** and find the application. Its status is **In Review**.
3. Select **Withdraw application** (the bin icon) on its row.
4. In the **Withdraw Application** dialog, select **Withdraw**.

## After completing

The application's status becomes **Withdrawn** and the list refreshes. One of your three application slots is free again.

## Troubleshooting

| What you see                            | What it means                                                                                                    |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| The withdraw fails and the list reloads | The application changed while you were looking at it — most often a decision landed first. Check its new status. |
| There is no **Withdraw** action         | The application is no longer pending.                                                                            |
