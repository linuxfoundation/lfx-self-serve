Use the Events section to find Linux Foundation events relevant to your projects and interests.

## Steps

1. Sign in to [app.lfx.dev](https://app.lfx.dev).
2. Select **Events** from the left navigation sidebar in the Me lens (`/events`).
3. Browse your upcoming and past events on the **Upcoming** and **Past** tabs.
4. Select an event to open its event page in a new tab. There is no separate event detail page in LFX Self Serve.

## What an event listing shows

The events table shows the following columns:

- **Event Name**
- **Foundation** — the foundation associated with the event
- **Date**
- **Location**
- **Role**
- **Status** — **Registered**, **Attended**, or **Not Registered**

Select **Event Name**, **Foundation**, **Date**, or **Location** to sort by that column.

On the **Upcoming** tab, events from your affiliated projects that you are not registered for show **Not Registered** and a **Register** button. On the **Past** tab, events you attended show **Download Certificate** — see [Download an Attendance Certificate](../attendance-certificates/).

## Filter and search

Use the tabs to switch between **Upcoming**, **Past**, [**Visa Letters**](../visa-letters/), and [**Travel Funding**](../travel-funding/).

On the **Upcoming** tab, choose a view:

- **My Registrations** — only the events you are registered for. This view is selected by default when you have at least one upcoming registration.
- **All Events** — _Upcoming events from projects you're affiliated with, plus any you're registered for across foundations._ Co-located events are left out of this list unless you are registered for them.

Narrow the list with:

- **Search events...** — find an event by name. On the request tabs the box reads **Search visa letters...** or **Search travel funding...**.
- **Foundation** — **All Foundations** or one foundation.
- **Role** — **All Roles**, **Attendee**, **Registered**, **Speaker**, or **Sponsor**.
- **Status** — **All Statuses**, **Registered**, **Attended**, or **Not Registered** on the **Past** tab. It isn't shown on the **Upcoming** tab. On the request tabs it filters by request status instead.

The **Foundation** and **Role** filters aren't shown on the **Visa Letters** and **Travel Funding** tabs.

## Register for an event

On the **Upcoming** tab, select **Register** on an event you aren't registered for. The event's registration page opens in a new tab, and you register there.

A new registration can take up to an hour to appear in your list. To find events beyond your projects, select **Discover Events** at the top of the page, which opens [events.linuxfoundation.org](https://events.linuxfoundation.org/).

## Empty states

- **No upcoming registrations** — _Events you register for will appear here._ Select **Browse all upcoming events** to switch to **All Events**.
- **No upcoming events** — _Events you're registered for and available to attend will appear here._
- **No past events** — _Events you've attended will appear here._
- **No results found** — _Try adjusting your filter criteria_. Select **Reset filters** to clear them.

Your events are on the Me lens Events page. If you're in another lens, switch to **Me** and select **Events**.
