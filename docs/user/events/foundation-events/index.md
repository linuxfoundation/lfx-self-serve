The **Foundation Events** page lists the events hosted by the selected foundation and its ecosystem, so you can see what is coming up, which events are open for registration, and how past events went.

## Who can see it

The **Events** item appears in the Foundation lens sidebar for board members, LF staff, and anyone with write access to the foundation. People who reach the Foundation lens only through a marketing role see the marketing pages instead.

## Open Foundation Events

1. Sign in to [app.lfx.dev](https://app.lfx.dev).
2. Switch to the **Foundation** lens and pick a foundation in the sidebar.
3. Select **Events** from the left navigation sidebar, or go to `/foundation/events`.

The page header reads _Events hosted by \<foundation\> and its ecosystem._ **Discover Events** opens [events.linuxfoundation.org](https://events.linuxfoundation.org/) in a new tab.

## What you see

Four stat cards sit at the top: **Total Events**, **Upcoming Events**, **Registration Open**, and **Past Events**.

Below them, three tabs, each with a count:

- **Upcoming** — events that haven't happened yet
- **Registration Open** — upcoming events that are taking registrations now
- **Past** — events that have ended

### Columns

| Column                  | Contents                                                                                      |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| **Event Name**          | The event; select it to open the event's page in a new tab                                    |
| **Type**                | The kind of event                                                                             |
| **Date**                | When the event runs                                                                           |
| **Location**            | Where the event is held                                                                       |
| **Registration Status** | **Registration Open**, **Coming Soon**, or **Completed**                                      |
| **Attendees**           | How many people attended (**Past** tab only)                                                  |
| **Action**              | **View Details** on upcoming events, **View Recap** on past events — both open the event page |

## Search and filter

- **Search foundation events...** — find an event by name.
- **Status** — **All Statuses**, **Coming Soon**, **Completed**, or **Registration Open**. The filter is hidden on the **Registration Open** tab, which already shows only those events.
